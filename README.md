# Customer Churn Analysis

This project focuses on analyzing customer churn using Power BI to identify the key factors driving customer attrition and provide actionable insights for retention strategies.

## Project Overview
The goal of this analysis is to understand customer behavior and uncover the reasons why customers stop using the service. By visualizing critical KPIs and trends, the dashboard helps in making data-driven decisions to reduce churn rates.

## Dashboard File
- **customer churn data analysis dashboard1.pbix**: The main Power BI file containing the data model, visualizations, and interactive reports.

## Key Insights & Features
- Overview of total customers, churned customers, and churn rate.
- Segmentation of churn by demographics (like age, gender) and account information (like tenure, contract type).
- Identification of patterns among high-risk customers.
